# California Housing Price Prediction using Decision Tree Regressor

A machine learning project built with Python and Scikit-Learn that predicts median house values using the **California Housing dataset** (`fetch_california_housing`). The project implements regression modeling via a **Decision Tree Regressor** (`DecisionTreeRegressor`)[cite: 3].

## 📋 Features

* **Data Loading & Prep**: Fetches housing data and structures it into a Pandas DataFrame with features like median income, house age, average rooms, and geographical coordinates[cite: 3].
* **Machine Learning Model**: Trains a supervised `DecisionTreeRegressor` with custom parameters (such as `max_depth=5`) for continuous value prediction[cite: 3].
* **Model Evaluation**: Assesses model fit and performance using $R^2$ scoring metrics across training and test splits[cite: 3].

## 🛠️ Tech Stack

* **Python**[cite: 3]
* **Pandas & NumPy** (Data manipulation)[cite: 3]
* **Scikit-Learn** (Dataset, Decision Tree Regressor, and train-test splitting)[cite: 3]
